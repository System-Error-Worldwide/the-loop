# v0.1 shipping manifest

SYSTEM ERROR'S THE LOOP v0.1 ships all 31 portable `SKILL.md` packages. Setup
installs the integrity-pinned pack and its offline toolkit, Doctor verifies the
installed result, and every packaged capability includes a bundled fallback that a
compatible harness can execute without a separately installed specialist.

## Protocols

All ten protocols are required because `the-loop-auto` is not safe without them:

1. Stage contracts.
2. Skill routing.
3. Code and non-code tracks.
4. Workflow dispatch.
5. Autonomy policy.
6. Run state and leases.
7. Issue ledger.
8. Evidence contract.
9. Watcher contract.
10. Harness capability map.

## Harness adapters

- Codex: project skills under `.agents/skills`, explicit invocation through Codex skill selection, and no assumption that a named subagent API exists.
- Claude Code: project skills under `.claude/skills` or a thin plugin adapter, with Claude-only frontmatter kept out of portable core files.
- Kimi Code: project skills under `.agents/skills` or `.kimi-code/skills`, with manual invocation supported through `/skill:<name>`.
- OpenCode: project skills under `.agents/skills` or `.opencode/skills`, with skill permissions checked by the doctor.
- DeepSeek Harness: project skills under `.agents/skills` or `.dsh/skills`, with
  `/name` invocation and host permission denial preserved by the adapter.

## Required repository material

- Portable `SKILL.md` packages with only standard cross-harness frontmatter.
- Protocol documents and machine-readable schemas.
- An exact SHA-256 release-integrity inventory covering every offline-toolkit file;
  Setup, Doctor and deterministic conformance fail closed on any mismatch.
- Setup and doctor commands.
- Synthetic fixtures and conformance tests for all five adapters.
- `PROVENANCE.md`, per-skill records, contribution guidance and release checks.
- A versioned launch manifest that supplies repository, quickstart, provenance,
  examples and CTA data to the separately owned page at
  `https://systemerror.app/the-loop`.

## Execution model

All 31 packages are complete instruction surfaces. A harness can load and execute any
of them directly. Setup, Doctor and the Python toolkit add repeatable installation,
state management, leases, budgets, authority checks and conformance evidence. Parallel
also uses toolkit lane primitives. This extra automation is additive; it does not
create separate shipping tiers.
