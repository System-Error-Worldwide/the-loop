# Synthetic non-code example

This example asks THE LOOP to: **Produce a factual one-page decision brief for a synthetic community workshop.**

It demonstrates the non-code track using only a synthetic three-note source packet.
Strategize defines the reader and decision, Spec-pack locks source and format rules,
Build drafts within those rules, Test maps every factual statement back to a supplied
note, and Close reports any remaining uncertainty.

The run halts when a required fact is absent, a claim cannot be sourced, personal data
appears, or publication is requested. The machine-readable fixture is at
[`tests/fixtures/conformance/assets/noncode.json`](../../tests/fixtures/conformance/assets/noncode.json).
